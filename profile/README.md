# 灵析 LingXi

灵析为公益组织、学校与社区团体提供数字化工具：表单与活动报名、联系人管理、捐赠与筹款等，让机构把更多时间留给服务本身。

LingXi builds digital tools for nonprofits, schools and community groups — forms and activity registration, contact management, donations and fundraising.

| 灵析（中国内地） | https://www.lingxi360.com |
| 靈析 Global（香港 / 國際版） | https://www.lingxi.com.hk |

## 在 AI 助手中使用灵析 · LingXi in your AI assistant

**[lingxi-global](https://github.com/lingxi/lingxi-global)** — 让 Claude、Codex 等 AI 助手直接处理靈析 Global 的表单、活动报名与联系人，首次使用时一步步引导连接帐号。

```bash
claude plugin install lingxi-global --marketplace lingxi/lingxi-global
```

或把这句话发给你的 AI 助手 / or send this to your AI assistant:

> 请阅读 https://mcp.lxi.hk/mcp/install.md ，帮我安装灵析 Global。
