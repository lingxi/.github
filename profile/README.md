# LingXi

LingXi builds digital tools for nonprofits, schools and community groups — forms and activity registration, contact management, donations and fundraising — so organizations can spend more time on the work that matters.

| Product | Website |
| --- | --- |
| LingXi (Mainland China) | https://www.lingxi360.com |
| LingXi Global (Hong Kong / international) | https://www.lingxi.com.hk |

## Use LingXi in your AI assistant

**[lingxi-global](https://github.com/lingxi/lingxi-global)** lets Claude, Codex and other AI assistants work with your LingXi Global forms, activity registrations and contacts, and guides you through connecting your account the first time.

```bash
claude plugin install lingxi-global --marketplace lingxi/lingxi-global
```

Or send this sentence to your AI assistant:

> Please read https://mcp.lxi.hk/mcp/install.md and install LingXi Global for me.

## For developers

- [api-client](https://github.com/lingxi/api-client) and [api-authentication](https://github.com/lingxi/api-authentication) — PHP client and request signing for the LingXi open API
- [lingxiapi-docs](https://github.com/lingxi/lingxiapi-docs) — LingXi API documentation

# 灵析

灵析为公益组织、学校与社区团体提供数字化工具，包括表单与活动报名、联系人管理、捐赠与筹款等，让机构把更多时间留给服务本身。

| 产品 | 网站 |
| --- | --- |
| 灵析（中国内地） | https://www.lingxi360.com |
| 灵析 Global（香港 / 国际版） | https://www.lingxi.com.hk |

## 在 AI 助手中使用灵析

**[lingxi-global](https://github.com/lingxi/lingxi-global)** 让 Claude、Codex 等 AI 助手直接处理灵析 Global 的表单、活动报名与联系人，第一次使用时会一步步引导你连接帐号。

```bash
claude plugin install lingxi-global --marketplace lingxi/lingxi-global
```

或者把这句话发给你的 AI 助手：

> 请阅读 https://mcp.lxi.hk/mcp/install.md ，帮我安装灵析 Global。
